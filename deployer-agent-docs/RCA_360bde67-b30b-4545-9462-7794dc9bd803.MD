# RCA — Deploy failed at pull_source (dev-foxy-pull)

## Outcome
Deploy failed. Two attempts (run `a05af993-bb2c-4a1f-9b6e-a058391c440a`, then fresh run `360bde67-b30b-4545-9462-7794dc9bd803`) both failed at the **pull_source** step with the identical, deterministic error.

## Failed step
`pull_source` — `kind: deploy_failed`

## Terminating error
```
prepare build context: read envs: read env file backend/.env:
open /tmp/agent-env-...-/app/backend/.env: no such file or directory (PathError)
```

## Root cause
`pull_source` packages the source from the agent-env (preview) pod and reads the env files declared in the template's `config.yaml` `env_paths` — for the `fastapi_react_mongo_shadcn` (farm) template those are `backend/.env` and `frontend/.env`. The file **`backend/.env` does not exist** in the preview source tree (`/app/backend/.env`), so context preparation aborts before any build/image work happens.

This is deterministic (reproduced on a clean retry with a new temp path), i.e. NOT a transient copy/infra blip.

## Why I did not "fix" it in the manifest
- `backend/.env` lives in the user's preview/agent-env pod. No deployer tool can write to that source.
- Removing `backend/.env` from `config.yaml`'s `env_paths` would let pull_source pass, but the FastAPI backend would then deploy with **no environment** (missing `MONGO_URL`, `DB_NAME`, etc.), failing at runtime. That masks the issue rather than fixing it.

## Fix (must be applied in the preview/source environment, then re-trigger)
1. Create `backend/.env` at `/app/backend/.env` in the preview environment.
2. Populate it with the backend config the app expects (at minimum `MONGO_URL`, `DB_NAME`, plus any API keys the code reads via `os.environ`). Confirm `frontend/.env` also exists (it holds `REACT_APP_BACKEND_URL`).
3. Re-trigger the deploy. pull_source will then find both env files and proceed.

## Note
No source archive was produced (pull_source failed pre-archive), so an eph sandbox reproduction was not possible — diagnosis is from the pipeline error, confirmed deterministic across two runs.
